
# 🎨 ColorWar

**ColorWar** is a web-based gaming project designed around a colorful, competitive experience with a clean and modern user interface.

The project combines interactive gameplay, animated interfaces, and a flexible foundation for single-player and online multiplayer experiences.

---

## ✨ Features

- 🎮 **Single Player** — Enjoy the game on your own.
- 🌐 **Online Multiplayer** — A foundation for competitive online gameplay.
- 🎨 **Colorful Game Experience** — A visual identity built around color and competition.
- 🏆 **Victory Screen** — Celebrate your achievements with a dedicated end-game experience.
- 🖥️ **Modern UI** — Clean interface design with animated interactions.
- ⚡ **Fast Development** — Powered by React and Vite.
- 📱 **Responsive Design** — Designed with adaptable layouts in mind.

> Note: Feature availability may depend on the current implementation of the project.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm

### 1. Clone the repository

```bash
git clone https://github.com/abacdai/ColorWar.git
```

```bash
cd ColorWar
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env` file in the project root if your current implementation requires environment variables.

Example:

```env
GEMINI_API_KEY=your_gemini_api_key
```

> Never commit API keys or other sensitive credentials to your repository.

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.
